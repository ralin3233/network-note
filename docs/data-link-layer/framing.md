# 成框 Framing

## 為什麼需要成框

實體層送出來的只是一長串位元，接收端不知道「一個訊息從哪裡開始、到哪裡結束」。成框就是在位元流中標出邊界，讓接收端能正確切出一個個框 (frame)。

## 常見成框方法

### 字元計數 (Character Count)
在框的開頭放一個數字，說明這個框有多長。
