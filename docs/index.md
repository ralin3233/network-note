# 網路課程筆記：實體層與資料連接層

這份筆記整理自課堂內容，目標是讓**沒有上過這堂課的人**，光看這份筆記也能理解實體層 (Physical Layer) 與資料連接層 (Data Link Layer) 的核心概念。

## 怎麼讀這份筆記

- 每個章節先講「這是什麼、為什麼需要它」，再進入技術細節
- 有公式的地方（CRC、Hamming Code）會附上一步步的計算範例
- 圖片盡量取代文字描述——訊號波形、frame 格式這類東西用看的比用讀的快很多

## 章節導覽

### [實體層 Physical Layer](physical-layer/index.md)
負責把「位元」變成實際可以在媒介上傳送的訊號。

### [資料連接層 Data Link Layer](data-link-layer/index.md)
負責把位元組織成有結構的框 (frame)，並處理錯誤偵測、流量控制。
