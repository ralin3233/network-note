# 實體層 Physical Layer 概論

## 這一層在做什麼

實體層是 OSI 模型的最底層，負責把上層傳來的「位元 (bit)」轉換成可以在實際媒介（電線、光纖、無線電波）上傳輸的**物理訊號**。它不關心資料的意義，只管把 0 和 1 送到對面去。

## 為什麼需要單獨一層來處理這件事

上層（資料連接層以上）只在乎「邏輯上的位元」，但現實世界的傳輸媒介有各自的物理限制：

- 電訊號會衰減、會被干擾
- 光訊號需要不同的收發元件
- 無線電波要考慮頻率、天線設計

實體層把這些「怎麼把位元變成物理訊號」的細節封裝起來，讓上層不用管硬體差異。
