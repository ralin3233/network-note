# 調變技術

## 為什麼需要調變

數位訊號沒辦法直接在某些媒介（例如無線電波、電話線）上有效傳輸，需要先「疊加」到一個載波 (carrier wave) 上，這個過程叫調變。

## 比較表

| 調變方式 | 改變的物理量 | 抗干擾能力 |
|---|---|---|
| ASK | 振幅 | 差 |
| FSK | 頻率 | 中 |
| PSK | 相位 | 好 |
