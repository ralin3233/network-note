    📑 核心內容規劃與章節脈絡¶

    新章節放置於 docs/physical-layer/ofdm.md，範圍精準從 Guard Band / Guard Time 出發，講授至 離散傅立葉轉換 (IDFT/DFT/FFT)：

    1. 單載波的高速物理瓶頸：
    2. 符號時間 \(T_s\) 隨高速傳輸極度壓縮。
    3. 大氣多路徑傳播（Multipath Propagation）與延遲擴展（Delay Spread \(\tau_{\max}\)）。
    4. 當 \(T_s < \tau_{\max}\) 時引發毀滅性的 符號間干擾 (Inter-Symbol Interference, ISI)，時域等化器複雜度爆炸。
    5. 分頻多工 (FDM) 的思路與保護頻帶 (Guard Band) 的代價：
    6. 將頻寬切分為 \(N\) 條慢速子通道，符號時間拉長為 \(T = N \cdot T_s \gg \tau_{\max}\) 瓦解 ISI。
    7. 傳統 FDM 為防頻譜重疊漏水而設立 保護頻帶 (Guard Band)，頻譜利用率低於 50% 且需要極度昂貴陡峭的類比濾波器。
    8. 時域防護：保護時間 (Guard Time) 與補零盲點：
    9. 於時域兩符號間插入保護時間 \(T_g \ge \tau_{\max}\) 阻隔跨符號衝撞。
    10. 剖析「純補零 (Zero-Padding)」的致命副作用：多徑延遲波在接收視窗被硬生生截斷，引發頻譜能量洩漏（Spectral Leakage），打破正交性並爆發 子載波間干擾 (ICI, Inter-Carrier Interference)。
    11. 神來之筆：循環前綴 (Cyclic Prefix, CP)：
    12. 將 OFDM 符號末端長度為 \(T_g\) 的波形直接複製貼到最前端。
    13. 三大魔法：
      1. 丟棄 CP 徹底清除前一符號的 ISI 殘影。
      2. 週期延拓使延遲波在積分視窗內仍為完整正弦波，徹底消滅 ICI。
      3. 將通道線性摺積轉化為圓周摺積 (Circular Convolution)，使頻域呈現 \(Y_k = H_k X_k + W_k\)，只需單抽頭頻域等化 (One-Tap Equalizer) 即可還原資料。
    14. 正交性 (Orthogonality) 的數學原理與頻譜重疊：
    15. 子載波頻率間隔條件：\(\Delta f = \frac{1}{T}\)。
    16. 正交性時間積分之嚴謹數學證明：\(\frac{1}{T} \int_0^T e^{j 2\pi (m-n)\Delta f t} dt = 0\) (\(m \ne n\))。
    17. Sinc 函數頻譜交疊之美：各子載波頻譜重疊 50%，但在彼此峰值中心頻率處，其餘子載波恰好落在零點（Zero-Crossings / Nulls），完全互不干擾。
    18. 硬體實作困境與離散傅立葉 (DFT / IDFT / FFT) 的奇蹟：
    19. 數千載波類比振盪器在硬體上不可行。
    20. 數學對應證明：連續 OFDM 基頻取樣訊號 \(s[n] = \sum_{k=0}^{N-1} X_k e^{j \frac{2\pi}{N} kn}\) 精確等於反離散傅立葉轉換 (IDFT)；接收端解調即為 離散傅立葉轉換 (DFT)。
    21. 結合 快速傅立葉轉換 (FFT)，運算複雜度由 \(O(N^2)\) 驟降為 \(O(N \log_2 N)\)，實現純數位晶片（DSP/FPGA）的高速調變解調。
    22. 附完整 OFDM 數位收發系統架構流程圖 (Transceiver Architecture)、精華對照總結表 與 初學者常見盲點 Q&A。

    1. 理論連貫性（不再分段獨立割裂）¶

    不再將保護機制與傅立葉轉換切成兩段獨立不相干的章節，而是以訊號傳輸的時頻物理制約貫穿整篇脈絡： * 時頻雙重防護：頻域以保護頻帶 (Guard Band) 避免相鄰頻譜滲漏干擾；時域以保護時間 (Guard Time) 阻斷多路徑反射殘影以消除 ISI。 * 串聯樞紐（核心連結）：深入論述「保護時間」如何強制將連續訊號切分成一段段固定長度 \(T\) 的「有限時間區塊 (Time Block)」，加上接收端的「數位取樣 (\(N\) 點)」，在頻域上自然引導出離散化正交頻點的需求，從而必然引出處理有限長度離散序列的核心工具——離散傅立葉轉換 (DFT)。

    2. 聚焦離散傅立葉轉換 (DFT) 的「純理論」部分¶

    已完全移除 OFDM 調變/解調系統應用（不提頻域符號映射、IDFT 調變器、DFT 解調器等具體系統設計），專注於純訊號處理理論： * 正轉換 (Forward DFT) 與反轉換 (IDFT)：定義式及其幾何與物理投影意涵。 * 正交性 (Orthogonality)：複數指數基底在離散網格點上的正交證明與無串擾特性。 * 隱含週期延拓性 (Implicit Periodicity)：有限區塊在 DFT 下的圓周位移與圓周卷積理論本質。 * 計算理論 (FFT)：Cooley-Tukey 演算法利用對稱性與週期性，將 \(\mathcal{O}(N^2)\) 複雜度降至 \(\mathcal{O}(N \log_2 N)\) 的演算法突破。

    已為您重構 ofdm.md，修改重點如下：

    1. 主題自然連貫¶

    • 雙重防護機制：從頻域的「保護頻帶（防頻譜滲漏但浪費頻寬）」對比時域的「保護時間（防多路徑反射以消除 ISI）」。
    • 串聯樞紐：說明因為保護時間的劃分，訊號被切分成固定長度 \(T\) 的獨立「時間區塊」，晶片在裡面抓出 \(N\) 個取樣點，自然引導出問題：「電腦手裡只有這 \(N\) 個數字，要怎麼找出裡面藏了哪些頻率？」

    2. 像老師教學般的直覺概念解說（拒絕教科書式直接丟定義）¶

    • 耳朵聽和弦的比喻：說明傅立葉轉換本質上就是幫波形「抓出藏在裡面的音符」。
    • 音叉與共鳴（Resonance）的直覺：
    • 電腦如何做頻率檢測？就像拿特定頻率的「音叉」去比對。
    • 相乘並加總（點積 / 投影）：若頻率存在，波峰對波峰，乘積全為正，加總得到大數值（共振成功）；若頻率不存在，正負相消得 0。
    • 拆解公式積木：逐項對照解說 \(x[n]\)（取樣訊號）、\(e^{-j\frac{2\pi}{N}kn}\)（標準測試音叉）、\(\sum\)（共振加總）與 \(X[k]\)（檢測結果），接著簡單以「組裝播放樂曲」直覺帶過反轉換 IDFT。

    3. 收尾於「正交性 (Orthogonality)」—— 後續內容全部裁切¶

    • 學生心中的關鍵問題：「用第 \(k_1\) 號音叉去測，會不會被 \(k_2\) 號頻率干擾？」
    • 幾何直覺：以平面座標 \(X\) 軸與 \(Y\) 軸互相垂直、投影為 0 作為直覺比喻。
    • 數學驗證與向量圓周對稱性：說明 \(k_1 \ne k_2\) 時旋轉向量在複數平面上剛好轉滿整數圈、對稱抵消為 0 的本質。
    • 正交性結論：各離散頻率就像走在獨立軌道上，在同個時域區塊內混合也互不干擾。
    • 章節於此結束，不再贅述週期延拓、FFT 演算法或 OFDM 調變應用。
