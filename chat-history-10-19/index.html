    📋 現況分析¶

    • ofdm.md 已涵蓋：保護頻帶 → 保護時間 → 時域分塊取樣 → DFT/IDFT 直覺 → 正交性。
    • 缺口：
    • 只講「空白保護時間」，未說明真實 OFDM 使用的循環前綴 (CP)。
    • 未說明 FFT 如何把 DFT 的 \(N^2\) 運算降到 \(\frac{N}{2}\log_2 N\)。
    • 未說明 OFDM 發送／接收的完整流程。
    • 標題與 nav 不一致、缺章節編號、缺開頭引言與結尾總結。

    🧩 預計新增內容¶

    1. 循環前綴 (CP)：從「空白保護時間會造成 ICI」切入，說明複製尾巴如何讓延遲波形在 FFT 窗口內維持完整週期。
    2. 快速傅立葉轉換 (FFT)：先量化 DFT 的 \(N^2\) 代價，再以「分而治之」說明 FFT 的加速原理。
    3. OFDM 發送流程：位元 → 調變映射 → 串並轉換 → IDFT/IFFT → 加 CP → 並串 + DAC。
    4. OFDM 接收流程：降頻/ADC → 串並 → 去 CP → FFT → 單抽頭等化 → 解映射 → 並串。
    5. 端到端全貌、Q&A、精華總結與章末收尾。

    🎨 排版調整¶

    • 新增「核心觀念」引言與「本章地圖」表格。
